JesusOnline Ministries · Website analytics

Counting a response once across two sites

When someone responds on a JesusOnline landing page, they’re sent to a resource on Follow. I set up tracking so the team can see how many responses were selected and how many visitors reached the next page.

On the JesusOnline landing page

A visitor selects a response.

Counts as one conversion.

On the Follow site

Their next resource opens.

Recorded separately as a page visit.

How I removed the double count

The follow-up page used to trigger a conversion when it loaded. I moved that trigger to the response button in Google Tag Manager, removed the page-load conversion, and checked the journey in Google Analytics 4.
